Small on purpose.

Everything a floating task board needs, nothing it doesn't.

Stays visible while you work

Floats above your other windows, with a tray icon to show, hide, or quit.

To-do, Doing, On Hold, Done

Hide any column you don't need from the Columns menu — your choice is remembered.

Move cards, reorder columns

Drag a card between columns, or up and down within one to set priority order.

Know what's next

Set a due date and Low, Medium, or High importance, with a live countdown on the card.

Notes, not just titles

Add bold, italic, underlined, and linked text to any card before you save it.

Never falls behind

Checks for new releases on launch and installs them in place — no manual reinstall.

What's new.

v1.2.0 2026-08-26
  • Added an On Hold column between Doing and Done
  • Added a Columns dropdown to show or hide any column, remembered between restarts
  • Cards can now be dragged up and down to reorder within a column
  • Editing a card now has explicit Cancel and Save buttons
  • Added the Glassmorphism theme
  • Lightened the base grey in the Windows 2000 theme
  • The app now checks for updates on launch and installs them in place
v1.1.0 2026-08-24
  • Added three more themes: Light Minimalist, Neo-Brutalism, and Windows 2000
  • Added an optional rich-text description field, with bold, italic, underline, and link formatting
v1.0.0 2026-08-20
  • Initial release with three columns: To-do, Doing, Done
  • Drag and drop tasks between columns
  • Due date and importance level per task
  • Drag-to-trash delete, with an optional confirmation step
  • Always-on-top window with a tray icon
  • Tasks saved automatically to a local file
